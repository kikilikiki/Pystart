# Hello World

## Qu'est-ce que Python ?

**Python** est un langage de programmation : une façon d'écrire des instructions
que l'ordinateur peut comprendre et exécuter. Python est réputé pour être
lisible et proche de l'anglais, ce qui en fait un excellent premier langage.

## Qu'est-ce qu'un programme ?

Un **programme**, c'est une suite d'instructions exécutées **de haut en bas**,
une ligne après l'autre. Quand tu cliques sur **Executer**, Pystart lance un
interpréteur Python qui lit ton programme et fait ce qu'il demande.

## La fonction `print()`

`print()` **affiche** quelque chose dans le terminal (la zone en bas de Pystart).

```python
print("Hello World!")
```

Ce programme d'une ligne affiche :

```
Hello World!
```

- `print` est le nom de la fonction.
- Les **parenthèses** `( )` contiennent ce qu'on veut afficher.

## Les chaînes de caractères

`"Hello World!"` est une **chaîne de caractères** (en anglais *string*) :
c'est du **texte**. En Python, une chaîne est entourée de guillemets, soit
doubles `"..."` soit simples `'...'`.

```python
print("Bonjour")
print('Bonjour aussi')
```

Si tu oublies les guillemets, Python croit que tu parles d'une variable et
affiche une erreur `NameError`.

## Les commentaires

Un **commentaire** commence par `#`. Python **l'ignore** complètement : il sert
uniquement à expliquer le code aux humains.

```python
# Ceci est un commentaire : Python ne l'execute pas.
print("Hello World!")  # on peut aussi commenter en fin de ligne
```

## Exécuter un programme

1. Écris ton code dans l'éditeur, à droite.
2. Clique sur **▶ Executer** (ou appuie sur **F5**).
3. Regarde le résultat dans le **terminal**, en bas.
